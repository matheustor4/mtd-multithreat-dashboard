# MTD Multi-Threat Risk Assessment Dashboard

Interactive companion dashboard and open simulation dataset for the manuscript:

> **Quantifying Time-Based Moving Target Defense Against Simultaneous Persistent and Non-Persistent Threats: A Stochastic Petri Net Evaluation**  
> *Matheus Torquato*

## Live Interactive Dashboard

Access the live dashboard directly in your browser (no installation required):

**https://matheustor4.github.io/mtd-multithreat-dashboard/**

## Features

1. **Transient Evolution Explorer (`PAS-NP`, `PAS-P`, `Elusiveness`)**: Interactive Plotly curves across four fixed time-based MTD schedules (`15m`, `30m`, `45m`, `60m`) and the undefended baseline (`Baseline w/o MTD`) over a 720-hour (one-month) horizon, with zoom presets, schedule toggles, and toggleable 95% confidence interval bands.
2. **Unified Composite Protective Effect Simulator ($\text{PE}_H^{\text{AUC}}$)**: Dynamic sliders for persistent threat priority ($w_P \in [0\%, 100\%]$), mission horizon ($H \in [24\text{h}, 720\text{h}]$), and protection target threshold. Recomputes exact trapezoidal Area Under the Curve ($\Delta^{\text{AUC}}$) exposure reductions and weighted harmonic means on the fly, with optional overlay of the compensatory arithmetic mean and CSV export.
3. **Persistent State-Space Decomposition & Latent Foothold Risk**: Interactive time-slider decomposition partitioning the persistent state space into *Clean (Elusiveness)*, *Latent Foothold* ($P_{\text{FH}}$), and *Compromised (PAS-P)*, alongside the transient foothold wave $P_{\text{FH}}(t)$ and conditional foothold risk $P(\text{FH} \mid \text{Surv.})$.
4. **Raw TimeNET Dataset Hub**: Direct download access to all 15 raw TimeNET `.STAT_OUT.csv` files individually or as a single compressed archive (`data/mtd_timenet_raw_csvs.zip`).

## Raw CSV Schema

Each `.STAT_OUT.csv` file generated by [TimeNET](https://timenet.tu-ilmenau.de/) uses semicolons (`;`) as delimiters:
- **Line 1**: Replication count (`samples`) and convergence summary.
- **Line 2**: Column header (`time;mean;confidence_interval;epsilon;variance`).
- **Lines 3–722**: 720 transient evaluation points spanning `[0, 720]` hours.

## Running Locally

Because the dataset is bundled in `data/dashboard_data.js`, you can simply clone or download this repository and open `index.html` directly in any modern web browser (no local web server required).
